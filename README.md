# Whis

Локальный Android-клиент для распознавания подкастов и аудио на устройстве через `whisper.cpp`.

## Цель первой версии

- обычный Android-интерфейс без Termux и командной строки;
- выбор локального аудиофайла;
- выбор языка (`Auto`, RU, EN, ZH и др.);
- выбор локальной модели Whisper;
- полностью локальное распознавание без отправки аудио в облако;
- отображение прогресса и результата;
- экспорт текста в TXT/SRT.

## Движок

Планируемая основа: `ggml-org/whisper.cpp`, закреплённая на стабильной версии. Модели не хранятся в APK: приложение скачивает выбранную модель один раз и затем работает офлайн.

## Приоритет устройства

Первичная оптимизация и тестирование — Android/arm64, в первую очередь Samsung Galaxy S24 Ultra.

## Ближайший этап

Собрать минимальный APK: `выбрать аудио -> распознать локально -> показать текст`.
